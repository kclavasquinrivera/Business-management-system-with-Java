# Business Management System

A Java-based console application developed as part of a high school programming course using Code.org. This project simulates business operations by organizing different departments into a single application.

## Overview

The system provides a menu-driven interface with department-based login and tools for managing sales, inventory, marketing expenses, and financial information. It demonstrates the application of fundamental Java programming concepts to a practical business scenario.

## Key Features

- User Authentication: Validates login credentials and directs users to their assigned department.
- Sales Management: Processes transactions, calculates sales tax, simulates cash and card payments, and supports register closing.
- Inventory Management: Organizes products, manages suppliers, tracks purchasing expenses, and handles budget requests.
- Marketing Management: Manages advertising expenses, sponsorships, contracts, and promotional events.
- Financial Management: Tracks monthly and yearly sales, estimates tax obligations, and manages departmental budgets.
- Modular Design: Separates functionality into Java classes to organize the application's different responsibilities.

## Technologies

- Language: Java
- Data Structures:** 'ArrayList', 'HashMap'
- Programming Concepts: Object-Oriented Programming (OOP), classes, objects, constructors, loops, conditionals, and `switch` statements
- Interface: Console-based user interaction

## Project Structure

The application is organized into separate Java files, including:

- 'Main.java' — Application entry point and login flow
- 'Usuario.java' — User information and credentials
- 'BaseDatos.java' — Initial application data
- 'Caja.java' — Sales and checkout operations
- 'Inventario.java' — Product and inventory management
- 'Producto.java' — Product information
- 'Proveedor.java' — Supplier information
- 'Marketing.java' — Marketing operations
- 'Finanzas.java' — Financial calculations and budgets
